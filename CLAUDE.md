# Working rules for this repo

## Scope — never touch other systems
This repo contains several independent apps and scripts. **Only work on
`shift-logger/`.**

Do NOT read, modify, run, build, or otherwise touch any other app or system in
this repo — including `csr-pulse/`, `reports-app/`, and the `*.gs` Google Apps
Script files — unless the user explicitly directs you to that specific system.
Do not proactively suggest or offer changes to those other systems either.
