01 The big idea

One app for CSRs, a locked one for the CEO

CSRs just open their app and start — no password. The CEO has a separate screen, locked with one password. Both save to the same place online, so the CEO sees new work the moment it's added.
The CSR app
Open it, pick your name, shift and profile, and start writing down your work.
🔓 No password — just open it
save / read
The CEO screen
Watch every CSR live. Look only. Locked — CSRs don't have this password.
🔒 One password · CEO only
DB
  One shared online database (Supabase)
A CSR taps save → it lands here → the CEO's screen updates on its own. No refresh needed.

In plain words

  • Nothing comes from old sheets or ClickUp. What the CSRs type is the only source.
  • Only one password — for the CEO screen. The CSR app opens straight away.
  • Everything is live — new work shows up for the CEO right away.

It follows the profile

  • Many CSRs work the same shift, each on a different profile.
  • So the note goes to the next CSR on that profile — a Grid note waits for the next Grid CSR.
  • They tap “Noted”, so you can be sure it was read.

Why it helps

  • No more “did the last shift tell us about…?”
  • Nothing falls through the cracks between shifts.

What's saved

  • One report row per CSR · profile · shift (no CSR ID shown — just a hidden key).
  • One action row per thing logged; fields sit in details.
  • When status = submitted, the app blocks any further edits.

How it's built

  • React + Vite on Vercel — two apps (CSR open, CEO password-locked).
  • Supabase database with live updates.
  • Hand-off note = latest unread note where profile = yours.
